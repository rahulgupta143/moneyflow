# 💰 MoneyFlow - Money Tracker

MoneyFlow is a simple and modern money tracking web application designed to help users manage their **earnings, expenses, savings targets, and daily earning streaks** in one place.

The application provides a clean dashboard where users can easily track their financial activity and monitor their progress toward their earning target.

---

## ✨ Features

- 💰 Track daily earnings
- 💸 Track daily expenses
- 🎯 Set an earning target
- 📊 View earning progress
- 📅 Date-wise transaction history
- 🚬 Cigarette expense category
- 🍔 Food expense tracking
- 🚕 Travel expense tracking
- 🛍️ Shopping expense tracking
- 🧾 Bills and other expense categories
- 🔥 Daily earning streak
- 🏆 Best earning streak
- 🎁 Daily reward system
- 🗑️ Delete earnings and expenses
- 📱 Responsive mobile-friendly design
- ☁️ MongoDB database support
- 🔄 Data shared through the backend
- 🌙 Premium dark UI

---

## 🖥️ Dashboard

The dashboard provides a quick overview of:

- Total Earnings
- Earning Target
- Target Progress
- Remaining Target
- Today's Earnings
- Today's Expenses
- Total Expenses
- Total Entries
- Current Earning Streak
- Best Earning Streak
- Recent Activity

---

## 💵 Earning Tracker

Users can add earnings with:

- Date
- Amount
- Note

All earnings are stored and displayed in the earning history.

---

## 💸 Expense Tracker

Users can record expenses using different categories:

- Cigarette
- Food
- Travel
- Shopping
- Bills
- Entertainment
- Gym
- Other

Each expense can also include a date, amount, category, and note.

---

## 🔥 Daily Reward System

MoneyFlow includes an earning streak system to encourage consistency.

### Streak Milestones

| Streak | Reward |
|--------|--------|
| 3 Days | 🔥 3 Day Streak |
| 7 Days | 🏆 1 Week Hustle |
| 15 Days | 💎 Consistent |
| 30 Days | 👑 Money Master |

The application automatically calculates the current earning streak and best streak.
